# Простая 3D игра на Panda3D

Это простая 3D игра, созданная с использованием движка Panda3D на Python.

## Установка и запуск

### Требования
- Python 3.7 или новее
- Panda3D (уже установлен)

### Запуск игры

У вас есть два варианта игры:

1. **Базовая версия** (`main.py`):
   ```
   python main.py
   ```
   Простая игра с базовым управлением и сценой.

2. **Улучшенная версия** (`advanced_game.py`):
   ```
   python advanced_game.py
   ```
   Более сложная игра с коллизиями, анимациями и системой очков.

## Управление

- **WASD** или **Стрелки** - движение персонажа
- **ESC** - выход из игры

## Особенности игр

### Базовая версия (main.py):
- Простое 3D окружение
- Управление персонажем от третьего лица
- Камера следует за игроком
- Базовое освещение

### Улучшенная версия (advanced_game.py):
- Детализированная сцена с лабиринтом
- Коллизии со стенами
- Система сбора монет
- Анимированные объекты
- Улучшенное освещение
- Система очков
- Сообщение о победе при сборе всех монет

## Решение проблем

Если игра не запускается:

1. Убедитесь, что Panda3D установлен:
   ```
   pip install panda3d
   ```

2. Проверьте версию Python:
   ```
   python --version
   ```

3. Если отсутствуют встроенные модели, игра создаст простые объекты из примитивов.
