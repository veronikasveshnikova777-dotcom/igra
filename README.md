# Простая 3D игра на Panda3D

Это коллекция простых 3D игр, созданных с использованием движка Panda3D на Python.

## Установка и запуск

### Требования
- Python 3.7 или новее
- Panda3D (уже установлен)

### Запуск игры

У вас есть несколько вариантов игры:

1. **Рабочая версия** (`working_game.py`) - **РЕКОМЕНДУЕТСЯ**:
   ```
   python working_game.py
   ```
   Стабильная, протестированная версия с базовым функционалом.

2. **Приключенческая игра** (`adventure_game.py`):
   ```
   python adventure_game.py
   ```
   Продвинутая версия с коллизиями, анимациями и системой сбора монет.

3. **Базовая версия** (`main.py`):
   ```
   python main.py
   ```
   Простая игра с русским интерфейсом (могут быть проблемы с отображением).

4. **Английская версия** (`simple_game_en.py`):
   ```
   python simple_game_en.py
   ```
   Базовая версия с английским интерфейсом.

## Управление

- **WASD** или **Стрелки** - движение персонажа
- **ESC** - выход из игры
- **R** - перезапуск игры (в приключенческой версии)

## Решение проблем

### Если игра не запускается:

1. **Проверьте установку Panda3D:**
   ```
   pip install panda3d
   ```

2. **Проверьте версию Python:**
   ```
   python --version
   ```

3. **Запустите рабочую версию:**
   ```
   python working_game.py
   ```

### Если нет 3D моделей:
- Игры автоматически создают простые объекты из примитивов
- Это нормально и не влияет на игровой процесс

### Если проблемы с русским текстом:
- Используйте английские версии игр
- Или `working_game.py` с английским интерфейсом
